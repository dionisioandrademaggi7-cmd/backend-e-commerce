Política de Privacidade

Última atualização: Junho de 2026  ·  Dr. Marco Maggi  ·  Portugal

Quem somos

O responsável pelo tratamento dos teus dados pessoais é Dr. Marco Maggi, com sede em Portugal. Para qualquer questão relacionada com a tua privacidade, podes contactar-nos através do email recebimentodrmarco@gmail.com.

Que dados recolhemos

Ao criares conta e adquirires o nosso conteúdo, recolhemos os seguintes dados:

  • Nome completo — para personalizar a tua experiência
  • Endereço de email — para autenticação e comunicações relacionadas com a tua conta
  • Senha — armazenada de forma encriptada (bcrypt), nunca em texto simples
  • Dados de pagamento — processados exclusivamente pela Stripe; não guardamos números de cartão
  • Data de criação da conta e registos de acesso — para segurança e auditoria

Para que utilizamos os teus dados

  • Criar e gerir a tua conta de acesso
  • Verificar o pagamento e ativar o acesso ao conteúdo adquirido
  • Enviar comunicações relacionadas com a tua conta (recuperação de senha, confirmações)
  • Garantir a segurança da plataforma e prevenir acessos não autorizados

Não vendemos, alugamos nem partilhamos os teus dados com terceiros para fins de marketing. Nunca.

Com quem partilhamos os teus dados

Os teus dados são partilhados apenas com os seguintes prestadores de serviço, estritamente necessários para o funcionamento da plataforma:

Prestador Finalidade Política
Stripe Processamento de pagamentos stripe.com/privacy
Google (Gmail) Envio de emails transacionais policies.google.com

Durante quanto tempo guardamos os teus dados

  • Dados de conta — enquanto a tua conta estiver ativa ou até pedires a eliminação
  • Registos de acesso e segurança — máximo de 90 dias
  • Dados de pagamento — conforme as obrigações legais aplicáveis (faturação)

Os teus direitos

Ao abrigo do RGPD, tens os seguintes direitos sobre os teus dados:

  • Acesso — podes solicitar uma cópia de todos os dados que temos sobre ti
  • Retificação — podes corrigir dados incorretos ou incompletos
  • Apagamento — podes pedir a eliminação completa da tua conta e dados
  • Portabilidade — podes receber os teus dados num formato legível por máquina
  • Oposição — podes opor-te ao tratamento dos teus dados em determinadas circunstâncias

Para exercer qualquer um destes direitos, contacta-nos em recebimentodrmarco@gmail.com. Respondemos no prazo máximo de 30 dias.

Cookies e sessões

Utilizamos um cookie de sessão (sessao) estritamente necessário para manteres a tua sessão ativa após o login. Este cookie não é utilizado para rastreamento ou publicidade, não partilha informação com terceiros e expira ao fim de 30 dias ou quando fazeres logout.

Não utilizamos cookies de terceiros, Google Analytics, pixels de rastreamento ou qualquer outra tecnologia de rastreamento.

Segurança

Adotamos medidas técnicas para proteger os teus dados, incluindo encriptação de senhas, comunicações HTTPS, proteção contra ataques de força bruta e acesso restrito aos dados de produção.

Reclamações

Se considerares que o tratamento dos teus dados viola o RGPD, tens o direito de apresentar uma reclamação à autoridade de controlo portuguesa: Comissão Nacional de Proteção de Dados (CNPD).
